## Organisation

Use one lowercase kebab-case folder per artist and one Markdown file per song:

```text
tones/artists/<artist>/<song>.md
```

Display artist and song names with their correct spelling and capitalisation inside each guide. Start from the [tone guide template](../../templates/tone-guide.md), describe the result as an inspiration or interpretation, and add the finished guide to this index.
