# General Tones

Reusable tones organised by style, gain level, texture, or playing purpose live here.

## Index

- [Tight Heavy Metal Rhythm + Lead](tight-heavy-metal-rhythm-lead.md)

## Organisation

Use one lowercase kebab-case Markdown file per tone:

```text
tones/general/<tone-name>.md
```

Use a clear descriptive name, start from the [tone guide template](../../templates/tone-guide.md), and add the finished guide to this index.
